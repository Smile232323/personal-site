欢迎来到我的个人空间。

这个站点用 Astro 搭建，文章在本地用 Markdown 维护，再同步到 GitHub，由 GitHub Actions 发布。技术栈只是实现方式，真正想留下的是一份能回头复查的工作记录。

这里会写几条看起来不太相邻的线：Codex、Agent、服务器和网络排障；AI 辅助科研、模型评测和产品思考；视频制作、项目复盘，以及一些日常决策。它们的共同点很简单：我尽量写清楚遇到了什么、用什么证据验证、下次怎样少走一点弯路。

有些文章来自社区帖子、评论或本地资料。我会保留原始资料时间、整理时间和来源说明，把公开事实、个人判断和仍待核验的部分分开；涉及价格、政策、服务商和模型状态，也会明确写出时效边界。公开版本不会把私人配置、凭据或聊天细节带出来。

我不想把这里做成收藏链接的展示柜。更希望几个月后重新打开一篇文章时，仍能看见当时的判断依据，知道哪些结论还成立，哪些需要更新。读者如果能从中带走一个可复用的方法，这个站点就没有白写。
