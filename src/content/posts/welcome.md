这是一个由 Astro 驱动的个人站点。

内容会在本地后台编辑，自动同步到 GitHub，再由 GitHub Actions 发布到 GitHub Pages。

这里的内容大致分成几条线：一条记录 Codex、Agent、服务器和网络排障；一条记录 AI 辅助科研、模型评测和产品思考；另一条记录视频制作、项目复盘与日常决策。它们看起来跨度很大，但共同点是都尽量把“我遇到了什么、怎样验证、下次怎么复用”写清楚。

站点中的整理文章会保留原始资料时间、整理时间和来源说明。社区帖子只作为线索，公开版本会重新组织结构、删掉私人信息，并把个人判断与来源事实分开。涉及政策、价格、服务商和模型状态的内容，会在文章里写明复查边界。

我希望这里最后留下的不是一堆看过的链接，而是一套可以继续更新的工作记录：读者能从文章里找到方法，我也能在几个月后回到同一篇文章，知道哪些结论仍然成立、哪些地方需要改写。
