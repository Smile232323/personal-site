这篇帖子最吸引人的地方是几组对比图：输入只有几个词，画面却有明确的主体、光线、镜头和电影质感。评论区又有人用相近提示词生成不同版本，补充了模型之间的差异。

如果只看成片，很容易把结果归因于“提示词很神”。但真正能复用的部分通常在提示词之外：怎样把画面说清楚，怎样保持多张图的连续性，怎样判断一次生成到底改进了什么。

## 先写视觉合同，再写形容词

我会把一张图拆成六层，而不是一口气堆很多审美词：

| 层次 | 要说清楚的内容 |
| --- | --- |
| 主体 | 谁或什么在画面里，动作和状态是什么 |
| 场景 | 时间、地点、前景、中景和背景的关系 |
| 镜头 | 景别、视角、焦段感、运动方向和画幅 |
| 光线 | 主光、轮廓光、雾气、色温和明暗关系 |
| 材质 | 服装、金属、岩石、水面或胶片颗粒的触感 |
| 约束 | 不要出现的元素、构图禁区和连续性要求 |

例如，“宇航员在太空里”只是一个主题；“宇航员近景、右侧留出巨大行星、黑色哑光金属、低饱和冷光、宽银幕构图、人物面罩不反射文字”才是一份可以比较的视觉合同。每次只修改其中一层，才能知道画面变化来自哪里。

## 先做镜头表，再做九宫格

原帖提到用九宫格帮助生成连贯内容。这个方法的关键不是一次得到九张漂亮图片，而是先把镜头表写出来：

```text
镜头 01：远景，建立世界和光线方向
镜头 02：中景，主体朝向与镜头 01 一致
镜头 03：近景，保留服装、道具和主色
镜头 04：动作变化，背景元素不重新发明
```

然后固定画幅、主体设定、主色和光线方向，只让景别、动作或环境发生变化。生成结果后，先把它们按镜头顺序排在一起，再检查人物比例、道具位置、阴影方向和背景天气是否突然跳变。单张图很惊艳，放进序列后却接不上，是最常见的失败。

## 评论区的对比说明了什么

原帖回复里有人用相近提示词比较不同模型，也有人分享自己生成的画面。这样的图片很适合用来观察“同一意图在不同工具里的表现”，但不适合直接做模型排名。

要让对比有意义，至少要记录：

- 使用的模型和版本；
- 画幅、分辨率、采样或参考图设置；
- 是否经过放大、锐化、局部重绘或后期调色；
- 选图标准是什么，失败样本是否被保留。

如果只把最好的结果放在一起，读者看到的是展示页，不是可复现的实验。图片旁边留下输入、设置和修改点，才知道下一次应该从哪里开始。

## 一条更稳的生产链

我把这种工作流整理成六步：

1. 写镜头表，确定每张图在叙事里的作用。
2. 为主体、场景、镜头、光线和约束建立固定字段。
3. 每轮只改一个变量，保留上一轮提示词和失败结果。
4. 先选构图稳定的版本，再做放大和局部修复。
5. 检查手指、文字、透视、反射、边缘和重复纹理等常见伪影。
6. 组装成连续画面后，再决定是否需要旁白、字幕和动效。

这条链路把“审美好不好”拆成了可以检查的问题。画面不好看时，先判断是主体不清、镜头不稳、光线冲突，还是材质细节失真，再决定修改哪一层；不要每次都把提示词整体重写。
