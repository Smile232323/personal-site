本站使用本地 Sveltia CMS 编辑内容。保存后，macOS 后台同步服务会在短暂防抖后提交并推送内容文件；网络暂时不可用时，改动留在本地，恢复后再重试。公开页面由 GitHub Actions 构建并部署到 GitHub Pages。

## 内容从哪里开始

原始资料先留在本地知识库，博客只接收经过筛选的公开稿。写作时先确认来源和日期，再决定文章要解决什么读者问题，最后写复查条件。这样发布队列里的文章不会只是“我看过某个帖子”，而是有明确的阅读价值和公开边界。

## 发布前的四次检查

我会依次检查事实和来源、隐私与敏感操作、图片与链接、构建与搜索索引。当前站点会立即公开非草稿文章；如果以后恢复未来日期排期，还要额外检查首页、归档、标签、RSS、Pagefind 和 notes 是否提前展示。发布后从桌面和手机各打开一次，确认正文宽度、图片、导航和 PDF 链接都正常。

## 站点也需要维护记录

内容同步、依赖升级和部署失败留在提交记录里，文章本身只保留面向读者的结论。出现问题时，先看最近一次同步和构建状态，再判断是内容错误、配置变化还是网络问题。把站点当成长期项目维护，持续更新才不会只停留在口号上。
